# Chapters

**Long-form documents for ideas and questions too large for a list entry.**

A chapter is **derived, never authoritative**. The canonical list is
[`../features_and_functions.md`](../features_and_functions.md). If a chapter and
the feature list disagree, **the feature list wins.**

Every chapter is named for the code it belongs to, and is linked from that
code's entry, from every `Q-nn` it explains, and from `../README.md`.
